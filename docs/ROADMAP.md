# Project Amnion 2.0 - Future Roadmap

Project Amnion 2.0 wordt continu doorontwikkeld. Hieronder vind je de geplande uitbreidingen en features.

---

## 🎯 Geplande Features

### 🚀 1. Multi-Factor Authentication (2FA)
- Ondersteuning voor TOTP (Google Authenticator, Authy, 1Password) voor admin logins.

### 🌐 2. Multi-Node Architecture (Edge VPN Nodes)
- Mogelijke uitbreiding waarmee 1 centraal Amnion Dashboard meerdere externe sing-box Edge knooppunten in verschillende landen/regio's kan aansturen via gRPC / mTLS IPC.

### 🛡️ 3. Aanvullende Protocollen
- **ShadowTLS v3** integratie voor extra camouflage in zwaar gecensureerde omgevingen.
- **WireGuard / AmneziaWG** native inbound ondersteuning voor traditionele VPN-clients.

### 📊 4. Geo-IP & Verkeersanalyses (Privacy-Preserving)
- Geaggregeerde land- en bandbreedtegrafieken in het dashboard zonder individuele gebruikers privacy te schenden.
